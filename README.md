# IndustryBook — UI/UX Design Draft

기업회원 전용 B2B 카탈로그 플랫폼의 **신규 디자인 프로토타입**입니다.

## 원칙
- 기존 운영 사이트는 **기능과 필드 요구사항**의 참고 자료로 사용합니다.
- 디자인, 색상, 헤더, 메인메뉴는 **새 디자인 초안**을 적용합니다.
- 기업회원만 가입할 수 있으며 카탈로그 등록은 로그인 후 이용하는 시나리오입니다.
- PDF/PPTX는 페이지 단위 변환 후 세로 스크롤로 연속 열람, 동영상은 단일 플레이어로 열람합니다.
- 모바일/태블릿에서 카탈로그 페이지는 콘텐츠 영역의 전체 너비를 사용합니다.

## 메인 메뉴
홈 · 카탈로그 · 기업 찾기 · 관심 피드 / 상단: 검색 · 카탈로그 등록 · 언어 · 알림 · 로그인
로그인 후: 대시보드 · 마이페이지

## 페이지
index.html, catalogs.html, catalog-detail.html, companies.html, company-profile.html,
feed.html, register.html, login.html, signup.html, dashboard.html, mypage.html, notifications.html

## 실행
index.html을 브라우저에서 열어 테스트합니다. 브라우저 로컬 저장을 사용하는 데모이며 실제 API/계정 인증/파일 업로드/PDF 변환/자동 번역은 연결되지 않습니다.
